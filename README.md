# 리컴프 로그북 (인간개조 프로젝트)

6개월 리컴포지션(근육↑ 체지방↓)용 운동·식단·루틴 기록 앱이에요.
기록은 폰 안(브라우저 저장소)에만 저장돼요. 서버도, 로그인도 없어요.

- 앱 주소: https://leehanjun00.github.io/recomp/
- 시작일: 2026년 11월 13일(금) 아침 6시 10분, 밀기부터
- 일정: 평일 아침 운동, 밀기 → 당기기 → 하체 순환 / 주말은 자율

## 1. 폰에 설치하기

- **안드로이드**: Chrome으로 앱 주소 열기 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰**: Safari로 앱 주소 열기 → 공유 버튼 → **홈 화면에 추가**
  (Chrome 등 다른 브라우저 말고 Safari에서 해야 해요)

설치 후에는 홈 화면 아이콘으로 열면 돼요. 한 번 열어두면 헬스장 지하처럼 인터넷이 없어도 열려요.

## 2. 밤 9시 기록 알림 켜기

매일 밤 9시에 GitHub Actions(`.github/workflows/remind.yml`)가 폰으로 알림을 보내요.
그날 몸 상태 등록을 이미 마쳤으면 조용한 "완료" 알림으로 바뀌어요.

처음 한 번만 설정하면 돼요.

1. 앱에서 알림 켜기를 누르고 나온 **구독 정보(JSON)**를 복사해요.
2. 저장소 → Settings → Secrets and variables → Actions → **New repository secret**으로 두 개를 추가해요.
   - `PUSH_SUBSCRIPTION`: 1번에서 복사한 구독 정보
   - `VAPID_PRIVATE_KEY`: 따로 받아둔 비공개 키 (절대 공개하지 마세요)
3. Actions 탭 → **밤 9시 기록 알림** → **Run workflow**로 테스트 알림이 오는지 확인해요.

참고

- GitHub 예약 실행은 몇 분 늦게 올 수 있어요.
- 공개 저장소는 60일 동안 커밋이 없으면 예약 실행이 멈춰서, 워크플로가 50일마다 빈 커밋을 남겨 깨워둬요.
- 폰을 바꾸거나 앱을 다시 설치하면 구독 정보가 바뀌니 `PUSH_SUBSCRIPTION`을 새로 넣어주세요.

## 3. 백업 (중요)

기록은 그 폰에만 있어요. 아래 경우에는 지워질 수 있어요.

- 폰을 바꿀 때
- 앱(홈 화면 아이콘)을 삭제할 때
- 브라우저의 사이트 데이터를 지울 때
- 아이폰에서 앱을 아주 오래 안 열었을 때

그래서 **한 달에 한 번, 인바디 재는 날** `변화` 탭 맨 아래에서 **백업 저장**을 눌러 파일을 카카오톡 나에게 보내기나 구글 드라이브에 저장해두세요. 새 폰에서는 **백업 불러오기**로 그대로 복원돼요. **엑셀용 CSV**는 기록을 엑셀에서 보고 싶을 때 써요.

## 4. 앱을 수정했을 때

`index.html`을 고쳐서 올릴 때는 `sw.js` 맨 위의 `CACHE` 버전 숫자를 하나 올려주세요(예: `recomp-v29` → `recomp-v30`). 그래야 폰이 새 버전을 받아요. 기록은 그대로 남아요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| index.html | 앱 전체 (운동 기록, 휴식 타이머, 식단, 루틴, 변화 그래프, 백업) |
| manifest.webmanifest | 앱 이름, 아이콘, 설치 정보 |
| sw.js | 오프라인 실행용 캐시, 알림 수신 |
| .github/workflows/remind.yml | 매일 밤 9시 기록 알림 발송 |
| icon-*.png, apple-touch-icon.png | 홈 화면 아이콘 |
